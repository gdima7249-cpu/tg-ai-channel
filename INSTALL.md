# Установка с нуля — пошагово

Займёт около 30–40 минут. Понадобится:

- Telegram на телефоне или компьютере;
- аккаунт Google (для ключа Gemini);
- сервер (VPS) с Ubuntu 22.04 или 24.04, **расположенный не в России**: Gemini API не отвечает
  запросам с российских IP-адресов. Подойдёт самый дешёвый тариф (1 ядро, 1 ГБ памяти).
- компьютер, с которого вы подключаетесь к серверу (Windows, macOS или Linux).

---

## Часть 1. Telegram: канал и бот

### 1.1. Создайте канал

Telegram → «Новый канал» → название и описание → тип **Публичный** → придумайте ссылку,
например `t.me/my_games_memes`. Часть после `t.me/` — это username канала, он понадобится в шаге 3.

### 1.2. Создайте бота

1. Найдите в Telegram **@BotFather** (с синей галочкой) и нажмите «Запустить».
2. Отправьте `/newbot`.
3. Введите имя бота (любое, например «Ведущий канала»).
4. Введите username бота — должен заканчиваться на `bot`, например `my_games_poster_bot`.
5. BotFather пришлёт **токен** вида `1234567890:AAH...`. Сохраните его и никому не показывайте:
   с ним любой может писать от имени бота.

### 1.3. Сделайте бота администратором канала

Откройте канал → название канала вверху → «Администраторы» → «Добавить администратора» →
найдите бота по username → оставьте право **«Публикация сообщений»** → «Сохранить».

### 1.4. Узнайте свой chat id (для пробного режима)

1. Найдите **@userinfobot**, нажмите «Запустить» — он пришлёт ваш `Id` (число). Сохраните его.
2. Найдите **своего бота** по username и нажмите «Запустить» (`/start`). Без этого бот не сможет
   писать вам в личку.

---

## Часть 2. Ключ Gemini API

1. Откройте https://aistudio.google.com/apikey и войдите в аккаунт Google.
2. Нажмите «Create API key» и скопируйте ключ (начинается с `AIza...`).

Подписка Gemini в приложении для этого не нужна и не помогает — это разные вещи. У API есть
бесплатный тариф с лимитами. Если сайт пишет, что сервис недоступен в вашей стране, ключ создавайте
через VPN; на сервере за рубежом он будет работать.

---

## Часть 3. Сервер

### 3.1. Подключитесь к серверу

Хостинг после покупки VPS присылает **IP-адрес** и **пароль root**.

- **Windows 10/11:** нажмите Пуск → введите `PowerShell` → откройте.
- **macOS / Linux:** откройте «Терминал».

Введите (вместо `1.2.3.4` — ваш IP):

```bash
ssh root@1.2.3.4
```

На вопрос `Are you sure you want to continue connecting?` ответьте `yes`. Затем введите пароль —
**символы при вводе не отображаются**, это нормально, просто введите и нажмите Enter.

Если видите строку вида `root@имя-сервера:~#` — вы на сервере. Все команды ниже вводятся здесь.
Вставить скопированный текст: в PowerShell — правая кнопка мыши, в терминале — Ctrl+Shift+V.

### 3.2. Установите нужные программы

```bash
apt update && apt install -y git python3 python3-venv nano
```

### 3.3. Скачайте бота

```bash
useradd -r -m -d /opt/tgchannel tgchannel
```

```bash
sudo -u tgchannel git clone https://github.com/gdima7249-cpu/tg-ai-channel.git /opt/tgchannel/app
```

```bash
cd /opt/tgchannel/app
```

```bash
sudo -u tgchannel python3 -m venv .venv
```

```bash
sudo -u tgchannel .venv/bin/pip install -r requirements.txt
```

### 3.4. Впишите настройки

```bash
sudo -u tgchannel cp .env.example .env
```

```bash
sudo -u tgchannel nano .env
```

Откроется редактор. Стрелками переходите к строкам и впишите значения после `=` (без пробелов и кавычек):

| Строка | Что вписать |
|---|---|
| `TG_BOT_TOKEN=` | токен из шага 1.2 |
| `TG_CHANNEL=` | `@username` канала из шага 1.1, например `@my_games_memes` |
| `TG_PREVIEW_CHAT=` | ваш chat id из шага 1.4 — пока он заполнен, посты приходят **вам в личку черновиками** с кнопками «Опубликовать» / «Отклонить» |
| `GEMINI_API_KEY=` | ключ из части 2 |
| `CHANNEL_SIGNATURE=` | подпись под постами, например `@my_games_memes` (можно оставить пустым) |
| `CHANNEL_STYLE=` | тон канала — можно оставить как есть |

Сохранить и выйти: **Ctrl+O**, **Enter**, **Ctrl+X**.

### 3.5. Каналы-источники

Возьмите готовый список кандидатов:

```bash
sudo -u tgchannel cp sources.candidates.txt sources.txt
```

Отредактировать (добавить свои каналы, удалить лишние) можно так же через nano:

```bash
sudo -u tgchannel nano sources.txt
```

Формат: одна строка — один канал: `username тип`, где тип `news` (новости) или `meme` (мемы).

## Часть 4. Проверка

Все команды — из папки `/opt/tgchannel/app` (если переподключились к серверу, сначала `cd /opt/tgchannel/app`).

### 4.1. Проверить настройки

```bash
sudo -u tgchannel .venv/bin/python -m tgchannel check
```

Должны быть галочки ✓ у бота, канала, личного чата, Gemini и источников. Если где-то ✗ — смотрите
раздел «Если что-то не так» внизу.

### 4.2. Посмотреть, что читается из источников

```bash
sudo -u tgchannel .venv/bin/python -m tgchannel sources
```

В начале будут строки `канал (news): N свежих постов`. Каналы с `нет публичного превью` или
постоянным `0` удалите из `sources.txt`. Для работы нужно хотя бы 3–4 живых новостных канала и 2–3 мемных.

### 4.3. Пробный пост без публикации

```bash
sudo -u tgchannel .venv/bin/python -m tgchannel post --dry-run
```

Покажет текст поста и ссылку на картинку. Ничего не отправляется.

### 4.4. Пробный пост вам в личку

```bash
sudo -u tgchannel .venv/bin/python -m tgchannel post
```

Пока заполнен `TG_PREVIEW_CHAT`, пост придёт вам в личку черновиком с кнопками. Чтобы кнопки работали, нужна служба из шага 5.2.

## Часть 5. Автоматическая работа

### 5.1. Включить расписание (10 постов в день)

```bash
cp deploy/tgchannel.service deploy/tgchannel.timer /etc/systemd/system/
```

```bash
systemctl daemon-reload && systemctl enable --now tgchannel.timer
```

Проверить, когда следующий запуск:

```bash
systemctl list-timers tgchannel.timer
```

Посты выходят каждые ~1,5 часа с 08:30 до 22:00 по Москве (плюс случайно до 20 минут) — 10 в день.

### 5.2. Кнопки «Опубликовать / Отклонить» (режим одобрения)

Пока в `.env` заполнен `TG_PREVIEW_CHAT`, каждый пост приходит вам в личку черновиком с двумя кнопками:

- **✅ Опубликовать** — бот копирует пост (с картинкой) в канал;
- **❌ Отклонить** — пост никуда не уходит.

Чтобы бот реагировал на кнопки, включите службу, которая работает постоянно:

```bash
cp deploy/tgchannel-bot.service /etc/systemd/system/
```

```bash
systemctl daemon-reload && systemctl enable --now tgchannel-bot
```

Проверить, что работает:

```bash
systemctl status tgchannel-bot --no-pager
```

Старое сообщение без кнопок тоже можно опубликовать: в Telegram ответьте на него (свайп влево
или «Ответить») текстом `+` — бот скопирует его в канал.

### 5.3. Публиковать сразу, без одобрения

Если посты устраивают и проверять каждый не хочется:

```bash
sudo -u tgchannel nano .env
```

Сотрите число после `TG_PREVIEW_CHAT=` (строка должна стать `TG_PREVIEW_CHAT=`), сохраните (Ctrl+O, Enter, Ctrl+X).
Перезапускать ничего не надо — следующий пост уйдёт сразу в канал. Службу кнопок тогда можно выключить:

```bash
systemctl disable --now tgchannel-bot
```

Всё. Можно закрыть окно терминала — бот работает на сервере сам.

## Часть 6. Ещё каналы (сколько угодно)

Одна установка ведёт несколько каналов. Бот, ключ Gemini и одобрение в личке — общие; у каждого канала
свои источники, тема, стиль и своя память об опубликованном. Канал из частей 1–5 остаётся «основным».

### 6.1. Создайте канал в Telegram и добавьте того же бота администратором

Как в шагах 1.1 и 1.3 (новый бот не нужен).

### 6.2. Создайте канал на сервере

Имя — латиницей, например `news` (это только имя папки, не username канала). `--preset news` подставит
готовый список новостных источников (непроверенный), без него будет пустой образец.

Готовые пресеты (источники непроверенные, тема и стиль подставляются в `.env` сами):

| Пресет | Тема |
|---|---|
| `news` | главные новости дня |
| `tech` | технологии и гаджеты |
| `ai` | нейросети и ИИ |
| `kino` | кино и сериалы |
| `science` | наука и космос |
| `games` | игры и мемы |

Команда для проверки источников пресета записана в первых строках его файла (`presets/<имя>.txt`).

```bash
cd /opt/tgchannel/app && sudo -u tgchannel .venv/bin/python -m tgchannel new-channel news --preset news
```

### 6.3. Настройки канала

```bash
sudo -u tgchannel nano channels/news/.env
```

Впишите `TG_CHANNEL=@username_нового_канала`, тему (`CHANNEL_TOPIC=`, например «главные новости дня»),
при желании стиль и подпись. Сохранить: Ctrl+O, Enter, Ctrl+X.

### 6.4. Источники

Проверьте кандидатов и оставьте в списке только отмеченные ✓:

```bash
sudo -u tgchannel .venv/bin/python -m tgchannel probe rian_ru tass_agency rbc_news meduzalive bbcrussian
```

```bash
sudo -u tgchannel nano channels/news/sources.txt
```

### 6.5. Проверка и пробный пост

```bash
sudo -u tgchannel .venv/bin/python -m tgchannel --channel news check
```

```bash
sudo -u tgchannel .venv/bin/python -m tgchannel --channel news post --dry-run
```

### 6.6. Расписание для канала

```bash
cp deploy/tgchannel@.service deploy/tgchannel@.timer /etc/systemd/system/
```

```bash
systemctl daemon-reload && systemctl enable --now tgchannel@news.timer
```

Если у канала мало живых источников (меньше ~20 свежих постов в сутки), лучше 5 постов в день вместо 10 —
иначе модель начнёт брать что попало:

```bash
cp deploy/tgchannel5@.timer /etc/systemd/system/ && systemctl daemon-reload
```

```bash
systemctl disable --now tgchannel@news.timer && systemctl enable --now tgchannel5@news.timer
```

Для следующего канала (например `tech`) повторите 6.1–6.5 и включите `tgchannel@tech.timer`.
Служба кнопок одна на все каналы — после добавления канала перезапускать её не нужно.
Над каждым черновиком бот пишет, для какого он канала.

Список всех каналов:

```bash
sudo -u tgchannel .venv/bin/python -m tgchannel channels
```

Каждый канал — это отдельный запрос к Gemini на каждый пост: 3 канала × 10 постов = 30 запросов в день.
Следите, чтобы хватало лимита бесплатного тарифа (при нехватке в логе будет `429`).

## Полезное

Посмотреть последние записи журнала (что публиковалось, ошибки):

```bash
journalctl -u tgchannel -n 50 --no-pager
```

Опубликовать пост прямо сейчас, не дожидаясь расписания:

```bash
systemctl start tgchannel.service
```

Обновить бота до новой версии:

```bash
cd /opt/tgchannel/app && sudo -u tgchannel git pull && sudo -u tgchannel .venv/bin/pip install -r requirements.txt
```

Если включена служба кнопок, после обновления перезапустите её:

```bash
systemctl restart tgchannel-bot
```

Поменять время или число постов: отредактируйте строки `OnCalendar` в `/etc/systemd/system/tgchannel.timer`, затем:

```bash
systemctl daemon-reload && systemctl restart tgchannel.timer
```

Выключить автопубликацию:

```bash
systemctl disable --now tgchannel.timer
```

## Если что-то не так

| Сообщение (текст может немного отличаться) | Что делать |
|---|---|
| `токен бота не работает: Unauthorized` | Токен скопирован с ошибкой. Возьмите заново у @BotFather (`/mybots` → бот → API Token). |
| `TG_CHANNEL: Bad Request: chat not found` | Неверный username канала (нужен с `@`) или бот не добавлен в канал. |
| `Forbidden: bot is not a member` / `need administrator rights` | Бот не администратор канала или без права публикации — шаг 1.3. |
| `TG_PREVIEW_CHAT: chat not found` | Вы не нажали «Запустить» у своего бота (шаг 1.4) или число вписано неверно. |
| `Gemini недоступен с этого сервера` | Сервер находится в стране, которую Google не обслуживает. Нужен VPS в другой стране. |
| `Gemini 400: API key not valid` | Ключ скопирован не полностью. Создайте/скопируйте заново в AI Studio. |
| `Gemini недоступен или лимит исчерпан (…429)` | Исчерпан бесплатный лимит или Google перегружен. Бот попробует при следующем запуске. |
| `кончился дневной лимит, запомнил до …` | Нормально: лимит модели на сегодня исчерпан, бот до сброса (около 11:00 МСК зимой, 10:00 летом) сразу берёт следующую модель из `GEMINI_MODELS`. |
| `У всех моделей кончился дневной лимит Gemini` | Все модели исчерпаны — посты возобновятся после сброса. Уменьшите число постов или каналов. |
| `Gemini недоступен или лимит исчерпан (…404)` | Модели из `GEMINI_MODELS` сняты Google. Посмотрите актуальные названия в AI Studio и впишите в `.env`. |
| `свежих постов в источниках: 0` | Все каналы из `sources.txt` мёртвые/закрытые или ничего не писали за сутки. Добавьте другие. |
| `Модель решила пропустить` | Не нашлось подходящей темы — это нормально, пост выйдет в следующий раз. |
| `Нет канала news: создайте его командой …` | Опечатка в имени или канал не создан — шаг 6.2. Список: `python -m tgchannel channels` |
| Кнопки не нажимаются / «часики» и ничего | Не запущена служба кнопок — шаг 5.2. Логи: `journalctl -u tgchannel-bot -n 30 --no-pager` |
| `ssh: connect … timed out` | Неверный IP или сервер выключен — проверьте в панели хостинга. |
